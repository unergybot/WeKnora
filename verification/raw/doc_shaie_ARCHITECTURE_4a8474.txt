# SHAIE Architecture Design

> **Living Architecture Document** - Last updated: 2026-01-08

## Overview

SHAIE (Smart Hybrid AI for Enterprise) is an on-premise AI appliance that provides natural language access to enterprise data. Built on a modular architecture with self-hosted LLMs, it connects to CRM, ERP, MES systems and documents through a RAG (Retrieval-Augmented Generation) pipeline.

## Data Flow

### Chat Request Flow

```mermaid
sequenceDiagram
    participant U as User
    participant API as Chat API
    participant EMB as Embedding
    participant VS as Vector Store
    participant LLM as LLM

    U->>API: POST /chat {message}
    API->>EMB: Embed query
    EMB-->>API: Query vector
    API->>VS: Search similar docs
    VS-->>API: Top-K chunks
    API->>LLM: Generate with context
    LLM-->>API: Response
    API-->>U: {response, sources}
```

### Document Ingestion Flow

```mermaid
sequenceDiagram
    participant Admin as Admin API
    participant Loader as File Loader
    participant Dedup as Deduplication
    participant Proc as Processor
    participant VS as Vector Store

    Admin->>Loader: Load file
    Loader-->>Admin: Extracted text
    Admin->>Dedup: Check hash
    alt New Document
        Dedup-->>Proc: PROCESS
        Proc->>VS: Insert all chunks
    else Updated Document
        Dedup-->>Proc: MERGE
        Proc->>VS: Insert new chunks only
    else Duplicate
        Dedup-->>Admin: SKIP
    end
```

| Configuration | Pydantic Settings + YAML |

## Configuration

Settings are loaded from:
1. `config/settings.yaml` (primary)
2. Environment variables
3. Default values

**Key Settings:**
- `llm.model_path` - Path to GGUF model
- `llm.n_gpu_layers` - GPU offload (-1 = all)
- `embedding.model_name` - HuggingFace model
- `database.milvus_uri` - Vector store path
