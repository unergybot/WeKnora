## Implementation Plan

### Phase 1: Setup (30-60 minutes)
```bash
# Download models (~24GB total)
bash scripts/setup_qwen3_models.sh

# Expected time: 30-60 min depending on connection
```

### Phase 2: Testing (5-10 minutes)
```bash
# Test both models independently and combined
python scripts/test_qwen3_models.py

# Verify:
# - Models load correctly
# - GPU memory < 16GB
# - Inference works for Chinese text
```

### Phase 3: Configuration (2 minutes)
Update `config/settings.yaml`:
```yaml
embedding:
  provider: local
  model_name: models/embedding/qwen3-embedding-8b
  device: cuda:0  # P100
  batch_size: 16
  allow_cpu_fallback: false

rerank:
  model_name: models/rerank/qwen3-reranker-4b
  device: cuda:0  # P100
  batch_size: 8
  max_length: 8192
  allow_cpu_fallback: false
```

### Phase 4: Code Updates (20-30 minutes)
Implement the new classes (code provided in setup guide):
1. `Qwen3Embedding` class in `shaie/core/embedding.py`
2. `Qwen3Reranker` class in `shaie/knowledge/reranker.py`
3. Update `RerankSettings` in `shaie/config/settings.py`
4. Update factory functions to detect Qwen3 models

### Phase 5: Deployment (5 minutes)
```bash
# Restart SHAIE
docker compose restart shaie

# Monitor startup
docker compose logs -f shaie
```

### Phase 6: Vector Index Rebuild (1-4 hours, optional)
```bash
# Backup existing index
cp -r data/milvus.db data/milvus.db.bge-m3.backup

# Rebuild with new embeddings
python -m shaie.cli reindex --force
```

## Two-Stage Retrieval Pipeline

```
┌─────────────────────────────────────────────────────────────┐
│                     User Query                              │
│                "企业数据安全政策相关文档"                      │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ Stage 1: Fast Candidate Retrieval (Qwen3-Embedding-8B)     │
│ ┌─────────────────────────────────────────────────────┐   │
│ │ 1. Embed query → 4096-dim vector                    │   │
│ │ 2. ANN search in Milvus (10M+ vectors)              │   │
│ │ 3. Retrieve top-100 candidates                      │   │
│ │ 4. Latency: ~150-300ms                              │   │
│ │ 5. Hardware: P100 GPU (10GB VRAM)                   │   │
│ └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                           ↓
            100 candidate documents
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ Stage 2: Precision Reranking (Qwen3-Reranker-4B)           │
│ ┌─────────────────────────────────────────────────────┐   │
│ │ 1. Cross-encode query + each document               │   │
│ │ 2. Deep semantic relevance scoring                  │   │
│ │ 3. Sort by rerank scores                            │   │
│ │ 4. Return top-10 most relevant                      │   │
│ │ 5. Latency: ~1.5-2.5s for 50 docs                   │   │
│ │ 6. Hardware: P100 GPU (6GB VRAM)                    │   │
│ └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                           ↓
              10 highly relevant documents
                           ↓
┌─────────────────────────────────────────────────────────────┐
│ Stage 3: Answer Generation (Qwen2.5-14B)                   │
│ ┌─────────────────────────────────────────────────────┐   │
│ │ 1. Assemble context from top-10 docs                │   │
│ │ 2. Generate comprehensive answer                    │   │
│ │ 3. Latency: ~7-10s for 200 tokens                   │   │
│ │ 4. Hardware: RTX 3080 (10GB VRAM)                   │   │
│ └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                           ↓
            Final answer with citations
```
